ইনস্টলেশন গাইড

সহজ ৩টি ধাপে Banglish সেটআপ সম্পন্ন করুন

মিনিটখানেকের মধ্যেই আপনার প্রিয় ম্যাকে বাংলা টাইপ করার প্রস্তুতি নিয়ে ফেলুন।

1

ইনস্টলার রান করুন

প্রথমে Banglish_Installer.dmg ফাইলটি ডাউনলোড করে ওপেন করুন এবং ডাবল-ক্লিক করে ইনস্টল করুন।

ফাইলটি ডাউনলোড করতে ক্লিক করুন
2

লগ আউট ও পুনরায় লগ ইন

ইনস্টল শেষ হলে আপনার ম্যাক একবার Log Out করে আবার Log In করুন (অথবা Restart দিন)।

⚠️ বিশেষ দ্রষ্টব্য: নতুন ইনপুট সোর্স সিস্টেমে ইনডেক্স করতে macOS এই সেশন রিফ্রেশ প্রয়োজন করে।
3

কীবোর্ড লিস্টে যোগ করুন

System Settings ➔ Keyboard ➔ Text Input (Input Sources) ➔ ক্লিক করুন (+) বাটন ➔ Bangla সিলেক্ট করে Banglish অ্যাড করে নিন।

Shortcut: Ctrl + Space
